# Tier 1 — Easy Facade Tasks

Eight independent Java examples for the Facade design pattern.

1. **Task 1 — Home Theater:** movie setup and shutdown.
2. **Task 2 — Coffee Maker:** espresso and americano recipes.
3. **Task 3 — Computer Boot:** startup and shutdown sequence.
4. **Task 4 — Smart Room:** night and morning modes.
5. **Task 5 — Online Store:** inventory reservation, payment, and shipping.
6. **Task 6 — Aquarium:** morning and night routines.
7. **Task 7 — Document:** spelling, A4 formatting, printing, and PDF-byte export.
8. **Task 8 — Car Ignition:** engine start and stop.

## Run a task

Open one task folder in Terminal and run:

```bash
javac *.java
java Main
```

Each folder has its own `Main.java`, uses the default package, and can be compiled independently.

These are console simulations. Task 7 uses representative PDF bytes instead of a full PDF library so the example stays focused on the Facade pattern.
